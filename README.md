# Портфолио

Делаю внутренние цифровые инструменты для розничного холдинга: дашборды и радары для операционного контроля сети, CRM, Telegram-боты и Mini App, AI-ассистенты на LLM и RAG.
Беру задачу от «таблица в Excel и ручная раскраска» до работающего сервиса на сервере — с правилами расчёта, которые можно объяснить заказчику, и документацией для эксплуатации.
Аналитик в розничном холдинге с 2025 года. Делаю внутренние сервисы, дашборды, Telegram-боты и AI-ассистентов на LLM и RAG — от разбора задачи с заказчиком до деплоя. Python, TypeScript/Next.js, YandexGPT, PostgreSQL.

Все кейсы обезличены: названия компаний, точек и людей заменены, скриншоты сняты на синтетических данных.
